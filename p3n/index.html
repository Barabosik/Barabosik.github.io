Chrome, Edge and Brave

Select text on any page, right-click and pick p3n, then Check for AI. The score, the reasons and a rewrite open in the side panel, and Replace puts the rewrite where your text was.

Word and Excel

Select text in Word, or cells in Excel, and click Check for AI on the Home tab. Replace puts the rewrite back with each paragraph's style, and Ctrl+Z undoes it.

Download the manifest

p3n isn't in Microsoft's add-in store yet, so you add it once from this file. It loads from the web after that, so it updates by itself.

How to add it

Word or Excel on the web

  1. Open a document.
  2. Choose Home › Add-ins › More Settings › Upload My Add-in, and upload the file. This browser keeps it.

Microsoft's steps

Windows

  1. Share a folder and put the file in it.
  2. In Word or Excel, add the folder's network path under File › Options › Trust Center › Trust Center Settings › Trusted Add-in Catalogs, tick Show in Menu and restart.
  3. Choose Home › Add-ins › Advanced › Shared Folder › p3n.

Microsoft's steps

Mac

  1. Copy the file to this folder (for Excel, com.microsoft.Excel; make the wef folder if it's missing):~/Library/Containers/com.microsoft.Word/Data/Documents/wef
  2. Restart the app, then choose Home › Add-ins › p3n.

Google Docs

Select text in a doc and open Extensions › p3n. Check and rewrite in the sidebar; Replace selection keeps headings, lists and formatting, and one Ctrl+Z undoes it.

VS Code

Select text in any file and run p3n: Check for AI or p3n: Rewrite, from the right-click menu or the command palette. Results open in the p3n view beside your text, and Replace selection is one undo step.

Copy main.js, manifest.json and styles.css from the GitHub release into this folder, then turn on p3n in Settings › Community plugins:<your vault>/.obsidian/plugins/ai-pen/

Sublime Text

Select text and run p3n: Check for AI or p3n: Rewrite, from the right-click menu or the command palette. Results show right under your text, and Replace selection is one undo step.

Install with Package Control

  1. Open the command palette (Ctrl+Shift+P, or Cmd+Shift+P on a Mac), run Package Control: Add Repository, paste this address and press Enter: https://raw.githubusercontent.com/Barabosik/p3n-sublime/main/repository.json
  2. Run Package Control: Install Package and choose p3n. Package Control keeps it up to date from then on.

No Package Control commands in the palette? Run Install Package Control first.

Listing in review, for Sublime Text 4 (build 4107 or later). Once Package Control's review is done, step 1 goes away.

Other ways to install

By hand

This way it doesn't update itself.

  1. Choose Preferences › Browse Packages….
  2. Unzip the ZIP there and rename the folder to exactly p3n. Or run this in that folder:git clone https://github.com/Barabosik/p3n-sublime.git p3n
  3. Restart Sublime Text.
