Chrome, Edge and Brave

Select text on any page, right-click and pick p3n, then Check for AI. The score, the reasons and a rewrite open in the side panel, and Replace puts the rewrite where your text was.

Add to Chrome

From the Chrome Web Store. Edge and Brave install it from there too.

Word and Excel

Select text in Word, or cells in Excel, and click Check for AI on the Home tab. Replace puts the rewrite back with each paragraph's style, and Ctrl+Z undoes it.

Download the manifest

p3n isn't in Microsoft's add-in store yet, so you add it once from this file. It loads from the web after that, so it updates by itself.

On the web
Open a document, then Home › Add-ins › More Settings › Upload My Add-in, and upload the file. This browser keeps it. Microsoft's steps
Windows
Share a folder and put the file in it. In Word or Excel, add the folder's network path under File › Options › Trust Center › Trust Center Settings › Trusted Add-in Catalogs, tick Show in Menu and restart. Then Home › Add-ins › Advanced › Shared Folder › p3n. Microsoft's steps
Mac
Copy the file to ~/Library/Containers/com.microsoft.Word/Data/Documents/wef (for Excel, com.microsoft.Excel; make the wef folder if it's missing). Restart the app, then Home › Add-ins › p3n. Microsoft's steps

VS Code, Sublime Text and Obsidian

Select text in a file or a note and run p3n: Check for AI or p3n: Rewrite, from the right-click menu or the command palette. Results open beside your text in your editor's light or dark theme, and Replace selection is one undo step.

They aren't in the editors' plugin stores yet, so you install them from GitHub for now. These installs don't update themselves; the store versions will.

VS Code
On GitHub · store listing soon
Download the .vsix
In the Extensions view (Ctrl+Shift+X), choose … › Install from VSIX… and pick the file. VSCodium, Cursor and Windsurf install it the same way. Needs VS Code 1.90 or later. Full steps
Sublime Text
On GitHub · store listing soon
Download the ZIP
Choose Preferences › Browse Packages…, unzip it there and rename the folder to exactly p3n. Or run git clone https://github.com/Barabosik/p3n-sublime.git p3n in that folder. Restart Sublime Text. Needs Sublime Text 4, build 4107 or later. Full steps

Download main.js, manifest.json and styles.css into <your vault>/.obsidian/plugins/p3n/, then turn on p3n in Settings › Community plugins. Works on desktop and mobile. Full steps

Google Docs

Select text in a doc and open Extensions › p3n. Check and rewrite in the sidebar; Replace selection keeps headings, lists and formatting, and one Ctrl+Z undoes it.

Free to start

10 checks or rewrites an hour without an account, up to 5,000 characters each. For more, make an API key at p3n.si and paste it into the app.
