    Selected work

    Chess Analyzer

    A full Stockfish 18 game review that runs entirely in your browser through WebAssembly. Import a game from Chess.com or Lichess and every move gets classified, from brilliant to blunder, with accuracy by phase and live engine lines. Nothing leaves your device.

    JavaScript, WebAssembly, Web Workers. Share links are 63% shorter thanks to gzip.

    TETHER

    A grapple-swing precision platformer in a single HTML file. Five verbs (swing, release, dash, attack, steer) and nineteen hand-tuned levels across three worlds, each with a boss. Ghost replays, a level editor with JSON import and export, and a pipeline that checks every level can be finished.
